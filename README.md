# ZN Specialists website

Static site for ZN Specialist Recruitment Ltd, served with GitHub Pages from the `main` branch.

- 8 pages: `index.html`, `specialisms.html`, `jobs.html`, `why-zn.html`, `hire-talent.html`, `find-a-role.html`, `break-into-pharma.html`, `contact.html`
- Shared styles in `styles.css`, shared behaviour in `site.js`
- Images in `images/` (see `images/README.txt` for what goes where)
